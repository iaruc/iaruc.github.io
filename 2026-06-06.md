# What a Tokenizer Does

A tokenizer converts text into tokens (numerical IDs) that the model can understand.

For example:

```python
"I love statistics"
```

may become:

```python
[315, 8921, 441]
```

The model never directly sees raw text.

---

# What Inference Means

Inference means using the model to generate outputs.

For example:

```python
model.generate()
```

During inference:

- the model does not learn
- parameters are frozen
- the model only predicts the next token

---

# Why LoRA Exists

I also began learning the theory behind LoRA.

Instead of training billions of parameters, LoRA only trains small low-rank adapters attached to the original model.

This dramatically reduces:

- VRAM usage
- compute cost
- training difficulty

which makes fine-tuning possible even on free Colab GPUs.
